# 🌿 Doce Verde

## Sabor que cuida do futuro

A Doce Verde é uma empresa fictícia criada como projeto escolar para
demonstrar como empreendedorismo, inovação tecnológica e sustentabilidade
podem trabalhar juntos.

## 🎯 Objetivo

Criar uma marca de doces com uma proposta sustentável, incentivando o
consumo consciente e a redução de desperdícios.

## 💡 Nossa solução

A Doce Verde propõe produtos que unem:

- 🌱 Sustentabilidade
- 🍫 Sabor
- ♻️ Redução de desperdícios
- 💡 Inovação
- 🤝 Consumo consciente

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ♿ Acessibilidade

O site foi desenvolvido considerando boas práticas de acessibilidade:

- HTML semântico;
- imagens com texto alternativo (`alt`);
- navegação por teclado;
- foco visual em elementos interativos;
- formulário com `label`;
- contraste entre texto e fundo;
- menu responsivo;
- suporte a `prefers-reduced-motion`.

## 🔒 Dados fictícios

Este projeto **não utiliza dados pessoais reais**.

Não devem ser adicionados:

- CPF;
- telefone pessoal;
- endereço residencial;
- e-mail pessoal;
- documentos;
- outras informações pessoais dos integrantes.

Os dados utilizados no formulário são apenas demonstrativos.
